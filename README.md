# To-Do List App (MERN + TypeScript)

Mobile-first to-do app. Tasks are grouped by week (Mon–Sun) with open/completed counts.

**Stack:** React + Tailwind CSS (Vite) · Node.js + Express · MongoDB (Mongoose) · TypeScript everywhere.

```bash
# Backend
cd backend
npm install
npm run dev                

# Frontend 
cd frontend
npm install
npm run dev               
```
